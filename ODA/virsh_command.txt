-------------------------------------------------------------------------------
                        Manejo de VMs en ODA con virsh
-------------------------------------------------------------------------------
Referencia de virsh: https://www.redhat.com/en/blog/virsh-subcommands

La consola virtual, o virsh, es una utilidad de línea de comandos flexible para administrar máquinas virtuales (VM) controladas por libvirt, un conjunto de herramientas y una API para administrar plataformas de virtualización. Es la herramienta de administración predeterminada para máquinas virtuales basadas en el kernel de Linux (KVM) y también es compatible con Xen, VMware y otras plataformas.

El comando virsh permite administrar máquinas virtuales de forma interactiva o por lotes. También resulta útil para controlar máquinas virtuales desde la consola de Linux y se integra con scripts o herramientas de automatización. Mediante virsh, puede conectarse rápidamente a un servidor utilizando SSH (Secure Shell) y realizar operaciones en sus máquinas virtuales sin necesidad de una interfaz gráfica.

Comandos: 

# virsh list --all
 Id   Name          State
------------------------------
 3    rh8-vm01      running
 -    crc           shut off
 -    rh8-tower01   shut off

# virsh shutdown rh8-vm01 
Domain 'rh8-vm01' is being shutdown

# virsh start rh8-vm01 
Domain 'rh8-vm01' started
