-------------------------------------------------------------------------------
                Upgrade de Oracle Solaris Cluster (rolling mode)
-------------------------------------------------------------------------------

Metodo online con actualizacion solo de OSC :

Siga estas instrucciones para evitar que el sistema operativo Solaris se actualice al actualizar el software del clúster Solaris con el comando `scinstall`:

*Fase pre upgrade*
1. Validacion de espacio en zpool rpool 
# zpool list | grep rpool

2. eliminación de snapshots que no se esten utilizando si rpool > 80%
zfs destroy <snapshot>

3. Limpieza de servicios en mantenimiento
# svcs -xv
# svcadm disable svc:/system/auto-update:ehc
# svcadm disable svc:/system/auto-update:stackdb

NOTA: Antes de pasar al paso cuatro verifique estado de salud del cluster por medio del comando: #cluster status si algun recurso presenta algun fail haga lo siguiente:
1. Pregunte si el recurso esta bien 
2. Ejecute el comando: #/usr/cluster/bin/scha_resource_setstatus -R resource_name -G resource_group_name -s OK

4. Migrar recursos hacia el nodo 2 (si es necesario)
# clnode evacuate nodo_a_evacuar

5. Evacúe cualquier grupo de recursos que se esté ejecutando en un nodo de clúster de zona que se encuentre en el nodo que se va a actualizar.

# clresourcegroup evacuate -n zone-cluster-node -Z zone-cluster-name +

6.Verifique que la migración se haya completado correctamente.

# cldg status;clrg status -Z all;clrs status -Z all

*Fase de upgrade* 
1. Montar ISO
# mkdir -p /mnt/sru20_osc
# mount -f hsfs /var/tmp/osc-4_4_20_2_0-repo-incr /mnt/sru20_osc

2. Configurar publishers
# pkg unset-publisher ha-cluster
# pkg unset-publisher solaris
# pkg set-publisher -g file:///mnt/sru20_osc/repo ha-cluster
# pkg set-publisher -g file:///mnt/sru20_osc/repo solaris
# pkg set-publisher -e ha-cluster
# pkg set-publisher -e solaris

3. Validar paquetes
# pkg list -af ha-cluster-incorporation
# pkg list -af consolidation/cacao/cacao-incorporation
# pkg update -nv

4. Congelar el sistema operativo
# pkg freeze entire

3. Proceda con la actualización del clúster Solaris. (iniciando con el nodo sin recursos)
# scinstall -u update -b BE_Cluster_SRU20 -L accept

4. Validar Boot Enviroment (BE)
# beadm list

5. Reinicio de nodo
# init 6 

6. Validacion de BE activo y version actualizada
# beadm list
# pkg list -af ha-cluster-incorporation
# pkg list -af cacao

7. Validacion de cluster 
# cluster status

8. Descongele toda la integración una vez que la actualización se haya realizado correctamente:
# pkg unfreeze entire
