Metodo online con actualizacion tanto de OSC como Sistema operativo:

# uname -a

# pkg publisher
PUBLISHER                   TYPE     STATUS P LOCATION
solaris                     origin   online F https://pkg.oracle.com/ha-cluster/support/
solaris                     origin   online F https://pkg.oracle.com/solaris/support/
ha-cluster                  origin   online F https://pkg.oracle.com/ha-cluster/support/

This was achieved using the following:

pkg set-publisher \
-k /var/pkg/ssl/pkg.oracle.com.key.pem \
-c /var/pkg/ssl/pkg.oracle.com.certificate.pem \
-G "*" -g https://pkg.oracle.com/ha-cluster/support ha-cluster

pkg set-publisher \
-k /var/pkg/ssl/pkg.oracle.com.key.pem \
-c /var/pkg/ssl/pkg.oracle.com.certificate.pem \
-G "*" -g https://pkg.oracle.com/solaris/support solaris

pkg set-publisher \
-k /var/pkg/ssl/pkg.oracle.com.key.pem \
-c /var/pkg/ssl/pkg.oracle.com.certificate.pem \
-p https://pkg.oracle.com/ha-cluster/support solaris

Next, I upgrade just the OSC packages:

scinstall -u update -b osc4.20 \
pkg:/ha-cluster/group-package/ha-cluster-incorporation@4.4-20.2.0 \
pkg:/consolidation/cacao/cacao-incorporation@11.4-0.175.4.0.0.15.0

I then reboot the node and upgrade the other cluster nodes.
